Module 05
Digital Object (DOB)
Create, read and transfer a digital object on your local CKB chain.
Custom Cell + TYPE_ID

        
This lab uses a custom Cell format. Name, description, content type and content are on-chain. It is not a Spore DOB. The app preserves content on transfer; TYPE_ID enforces a unique identity.

        
Open this module to load DOB records.

Protocol & verification
Custom Cell + TYPE_ID

            
Object ID is the 32-byte TYPE_ID args. A transfer consumes the current Cell and creates one replacement Cell with the same type and data, locked to the receiver.

            
TYPE_ID is built into CKB; no DOB contract deployment is needed. An owner using an external transaction can change the data or destroy the Cell. This application detects data changes and refuses to transfer them.
